# attune-companion

attune-companion 是一个面向 DeepSeek 陪伴应用的开源组件，帮助玩家把自己写好的角色设定带进新会话，继续上次的话题，并决定这个角色可以记住什么。首个适配目标是 DeepSeek Harness（DSH）。项目目前处于 MVP 设计阶段，以下功能是首版交付目标。

比如，你曾告诉一个角色：“面试前别给我打气，先陪我练一道题。”几周后，你在新会话里说“明天又有面试了”，希望它还知道该怎么陪你。如果今天你说“这次我想听点鼓励”，它也应该听懂“这次”，保留你对下次的选择。

## 和 DSH 的关系

DSH 是首版插件运行的宿主，负责聊天界面、会话和模型调用。attune-companion 是独立的社区项目，负责保存角色设定、管理有来源的记忆，以及为当前一轮对话挑选需要带入的内容。上下文预算作用于最终发给模型的请求，让几个月的聊天记录可以留在历史里，只在相关时被取用。[DeepSeek 多轮对话文档](https://api-docs.deepseek.com/guides/multi_round_chat/)

已有的 `ajuwm/dsh-roleplay-plugin` 提供了 DSH 角色扮演的实现参考。attune-companion 会借鉴它在长对话中保持角色风格、在新会话中恢复场景的做法。首版通过 DSH 适配器验证这些能力，角色与记忆包采用单独定义的格式，方便其他客户端实现导入和导出。[DSH 社区角色扮演插件](https://github.com/ajuwm/dsh-roleplay-plugin)

## 第一版要做什么

1. **带入已有角色。** 玩家可以粘贴长提示词，保留原文，选出必须保留的语气、边界和对话示例，再试聊确认。命理风格可以作为可选的角色创作素材，由玩家决定是否采用。关于玩家本人的记忆以其实际表达为依据。
2. **在新会话里接着聊。** 每个角色有独立的记忆范围。插件在预算内组合角色设定、最近对话和相关旧事，并区分玩家的现实经历与虚构剧情。找不到依据时，角色可以询问玩家。
3. **查看、纠正和遗忘。** 玩家可以从一条记忆查看它来自哪句话，改正误解，或要求忘记。修改应从下一轮生效，重启后仍然有效，旧摘要也应随之更新。
4. **导出和恢复。** 玩家可以把角色版本、有效记忆、必要的来源片段和近期进度导出为带格式版本号的本地文件，并在新的环境中恢复。恢复的是这些可检查的内容，具体回复仍会随模型和设置变化。

## 怎样算首版完成

首版验收会使用一份可公开分发的示例角色卡。从 DSH 导入角色，聊出一个明确偏好，换会话后接着聊，再纠正这条偏好。最后将角色包导入一个最小 DeepSeek API 示例客户端，检查角色设定和修正后的记忆能否恢复，并比较续聊时实际发送的输入 token 数。玩家体验和开发者接入都可以沿用这个例子验证。
